# RollCode

RollCodeは、macOS向けの小さなコードエディタです。フォルダを開き、複数ファイルをタブで編集し、同じウインドウのターミナルでコマンドを実行できます。

## 現在の機能

- フォルダツリーとファイル名フィルタ
- `⌘P`によるパス検索とクイックオープン
- 最後に開いた作業フォルダの自動復元
- 複数タブ、未保存表示、保存・別名保存
- 括弧・引用符の補完、選択範囲の囲み、自動インデント
- 2・4・8スペースから選べるTab幅
- `⌘+` / `⌘-` / `⌘0`によるエディタのフォントサイズ拡大・縮小・等倍リセット
- 行番号と軽量なシンタックスハイライト
- ファイル内検索、一致箇所のハイライト、前後移動、`⌘L`による指定行ジャンプ
- Markdownファイルのリアルタイムプレビュー表示切り替え
- `⇧⌘F`によるプロジェクト全体検索・一括置換
- `⇧⌘G`によるGit変更ファイル一覧、差分プレビュー、エディタでの直接オープン、GUIコミット
- 言語・行数・フォントサイズ・文字コードを表示するステータスバー
- 外部アプリやGitによるファイル変更の自動再読み込みと競合確認
- `⌘W`でタブを閉じる操作、Finder表示、ファイル・フォルダの新規作成・名前変更・ゴミ箱への移動
- 内蔵zshターミナル、コマンド履歴、実行中コマンドの割り込み
- カスタムドラッグスプリッターによる滑らかなサイドバー・Agentパネルのリサイズ、開閉アニメーション、幅の永続化
- リサイズ可能なエディタと内蔵ターミナル
- RollCode専用のmacOSアプリアイコン
- Codex CLI / Gemini CLIを使ったAgentパネル、会話の継続、実行ログ、停止操作
- マルチプロバイダー対応（CodexとGeminiの最新スレッドをワンクリックで瞬時に切り替え）
- マルチスレッド管理（新規スレッド作成、会話切り替え、過去のCodexセッション履歴からの再開）
- 全般設定ウィンドウ（`⌘,`）によるエディタ設定（タブ幅・フォント）、AIプロバイダー設定、Google / ChatGPT アカウント管理
- Codex / Gemini のログイン状態表示と、ブラウザ経由のワンクリックUIログイン誘導（ChatGPT / Googleアカウント / APIキー）
- AIによるワークスペース変更の自動採用、変更ファイル一覧、Git差分プレビュー直接連携

## 開発

```sh
cd RollCode
xcodegen generate
open RollCode.xcodeproj
```

コマンドラインで確認する場合:

```sh
xcodebuild -project RollCode.xcodeproj -scheme RollCode -destination 'platform=macOS' test CODE_SIGNING_ALLOWED=NO
```
